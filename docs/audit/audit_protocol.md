## UGO: lowest introduction versus highest algorithm

The introduction says “lowest epistemic uncertainty”; Section 3.3's prose, Section 3.4's `argmax` and Table 4 say highest average uncertainty. The implementation selects `classes[int(np.argmax(means))]`, after computing class-wise fitting-sample MMA means. It follows the detailed algorithm/Section 3.4 over the conflicting introductory statement. The authors' uniquely intended behavior remains UNVERIFIED without code/clarification. Evidence: [paper source and page references: ugo](paper_sources.md#ugo), [paper source and page references: ugo](paper_sources.md#ugo), [src/ugo.py:226–244](../../src/ugo.py#L226).

This rule can select majority as well as minority. In the GNB runs, UGO added 42 majority-labelled rows on Ecoli4 and 1,200 on Yeast4 over 25 folds; these are not minority intrusions. Evidence: `docs/sshr_pilot/ecoli4/diagnostics.csv`, row 10; `docs/sshr_pilot/yeast4/diagnostics.csv`, row 10; `src/ugo.py:242,267`.

## SSHR's especially important objective issue

The printed objective uses `2*TP*TN / (TP*(TP+FP)+TN*(TP+FN))`, not conventional minority F1. This expression can exceed one, despite the paper's stated bound. The code implements it literally under `paper_printed` and flags anomalies. The final objective quantity exceeded one in 110 of the 200 SSHR jobs across both U settings/classifier copies; held-out standard F1 values remained bounded and matched the independent recomputation. Evidence: [paper source and page references: sshr](paper_sources.md#sshr), [src/sshr_clustering.py:72–89](../../src/sshr_clustering.py#L72), [audit_verification.json, datasets.*.runs.*.sshr_printed_final_objective_f1_anomalies_by_classifier](audit_verification.json), [audit_numbers.md](audit_numbers.md).

This is a **fidelity blocker**, not evidence that the presentation's held-out F1 numbers are invalid. It may affect clustering/selection, so negative U effects must be attributed to this audited implementation/protocol rather than declared a refutation of SSHR. No objective variant, gate or other policy was changed during this audit. Evidence: [src/sshr.py:103–118](../../src/sshr.py#L103), [command_evidence.txt:13–20](command_evidence.txt#L13).
